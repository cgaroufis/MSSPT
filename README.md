# MSSPT

This repository contains the latest version (v2) of the code to reproduce the experiments and results of the paper "[Pre-Training Music Classification Models via Music Source Separation](https://arxiv.org/pdf/2310.15845.pdf)", submitted to EUSIPCO-2024. Additional features include:

- Incorporation of the AST backend, apart from convolutional ones.
- Support for pre-training independently the backend network, or using a pre-trained set of weights for the backend for finetuning.

The code and the readme will be updated within the next few days; in the meantime, you can access the v1 from [here](https://github.com/cgaroufis/MSSPT/tree/main).
